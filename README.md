
# Shopping List Management System

## About the Project
This project is a menu-driven C++ application developed as a Data Structures case study. It helps users manage shopping items through a simple console interface.

## Features
- Add items to the shopping list
- Remove items from the shopping list
- Search for an item
- Display all shopping items
- Exit the application

## Data Structure Used
- **Vector:** Stores and manages shopping list items dynamically.

## Technologies Used
- C++
- Standard Template Library (STL)

## Concepts Covered
- Insertion
- Deletion
- Linear Search
- Iteration
- Menu-driven programming
- Switch statements and loops

## How to Run
1. Open `main.cpp`.
2. Copy the code into a C++ compiler.
3. Compile and run the program.
4. Select an option from the menu.
5. Enter the requested item name when prompted.
